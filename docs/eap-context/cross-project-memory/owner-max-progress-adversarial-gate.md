Owner standing operating directive, 2026-07-19 (verbatim excerpts): "Open PRs and surface questions as github comments with clear questions and context for impact. I don't want to see questions about 'oh this is very much the same, but it's a slightly different shape.. what to do?!' If an agent is uncertain, do an adversarial agent debate grounded in our current source of truth. A 'should I proceed?' isn't a real decision that should be gated on me. If you're not sure _how_ to proceed because there are competing interests, that's the sort of thing to surface. Use adversarial check agents as you go... My goal is to enable you to make AS MUCH PROGRESS as possible."

**Why:** the owner works async and wants throughput; permission-gating and trivial "which near-identical shape?" questions stall progress for no real decision. He has explicitly designated the project's adversarial/paired-fidelity verification machinery as the gate for uncertainty, not himself.

**How to apply:**
- DEFAULT TO PROCEEDING. Never send a bare "should I proceed?" — it is not a real decision.
- Resolve ambiguous reads / uncertain findings with the existing adversarial machinery: paired-fidelity re-reads, adversarial debate agents, multi-lens verification — grounded in the cited source of truth. That resolution IS the owner's preferred gate; don't escalate what the machinery can settle.
- Surface ONLY genuine COMPETING-INTEREST forks (two legitimate designs/paths that trade off against each other, where the choice has real consequences — e.g. fidelity vs cost, faithfulness vs road-legality) — and surface them as GitHub PR comments with clear question + impact context, on an open (draft if gating) PR, not as blocking chat questions.
- Applies to ALL research/sourcing lanes (harness pigtail/segment sourcing, odds-and-ends hardware, sibling-ID sweeps, and future ones): ordinary uncertainty — including sibling-vs-not / donor-match / "same family but slightly different shape" calls — resolves via adversarial debate grounded in the catalog + manual sources (redux R4 truth, the sourcing case files), NOT by asking the owner.
- Keep opening PRs and driving them; maximize progress.
