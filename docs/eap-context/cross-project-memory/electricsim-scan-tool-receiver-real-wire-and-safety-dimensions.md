Hard-won on PR #277 (BL-0140 scan-tool Mode-0x04 output-control receivers for AD/HTCM). Copilot review caught, across two rounds, 12 real issues that two dedicated HV-safety review passes had missed. The durable lessons:

**1. A receiver must drive the REAL published wire, and the test must assert it.** The HTCM pump/fan force initially only set scan-local `effective_*_cmd` / `scan->general.*_cmd` (a rollup), while the canonical actuator wires `CHASSIS_HTCM_*_FEED` are reconstructed by `htcm_publish_observability_cells()` from `sup.*_cmd` + the safety mask — so the force never reached the actuator, and the "wiring" test asserted the scan-local value (green while the real wire was unforced). Fix: fold the force into the publish seam alongside the safety mask (gated by `supply_present`), and make the test instantiate a real WireTable + call the production publish helper and assert the `*_FEED` bit. This is the AGENTS.md §4 "drive the real seam" rule applied to actuator output; `audit_assertion_density` does NOT catch a poke that asserts the wrong (scan-local) value.

**2. Safety-interlock coverage is multi-dimensional — enumerate them.** For an HV-contactor / actuator force, a review that only checks arbitration ORDERING misses: (a) weld gating — weld DTCs 007/008 do NOT set `fault_latched`, so a close-family force must explicitly check `weld_dtc_active_` at the top of the block, not rely on the fault-latch early-return; (b) input FRESHNESS — close-family energization (incl. precharge) must require `inputs_fresh_`, else de-energize to safe-open; (c) consumer-side generation-gating — a level-held command wire (kHold) must be read via `StaleGatedWire` so a hung producer ages to the safe default (remove the freshness allowlist entry so `audit_freshness` enforces it); the producer must heartbeat the wire every tick so a live-but-idle producer stays fresh; (d) session LIFECYCLE — a responder session + its latched force must reset to NONE on `key_on`/`key_off` (mirror HTCM's `oc_force` clear) so a force can't survive a power cycle; (e) continuous RE-VALIDATION — a latched close must re-check the live interlocks (stationary, park/not-drive, weld) each tick and auto-release to safe if any re-fails (owner ruling 2026-07-17), because the off-bus AD has no speed backstop; (f) contract honesty — an accepted request must actually mutate state (reject `arg=0` zero-duration as BAD_FAMILY_OR_SELECTOR rather than a no-op ACCEPTED).

**3. Practice.** When reviewing/authoring an actuator receiver, trace the force ALL the way to the published wire, and check each of the six dimensions above explicitly. Also: a test suite whose `main()` `return 0;` unconditionally (no `TEST_MAIN_FOOTER`) silently swallows failures — grep new test files for that pattern.
