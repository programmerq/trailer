Delivered 2026-07-20 (ev1 PR #23, thermal/ + decision file). KEY REFRAME: the EV1 has THREE physical thermal media, not four loops — (1) ONE shared HTCM-controlled liquid coolant loop (drive motor + power electronics + cabin heater core + charger receptacle as a valve-gated branch); (2) BPM-controlled air-cooled pack ventilation (blower 27003192, also gas purge); (3) R-134a reversible heat-pump cabin loop (reversing valve 27000715). No EV1 heat-load watts are printed anywhere (nulls per R4). COMPRESSOR CORRECTION: the original is a dual-rolling-piston 180V variable-speed 3-phase AC induction unit, P/N 27001056 (hvac-288) — NOT a scroll; the NANFENG NFDM34 remains a modern-substitute candidate with an architecture-difference caveat (case-file reconciliation dispatched). RECOMMENDATION Option B (consolidated): one active drive/PE liquid loop (EMP/Bosch WP32-class pump, salvage Leaf/Volt radiator, G-48); air-cooled pack + silicone pad heaters (LiFePO4's real risk is sub-0°C charge lockout); reversible heat-pump cabin (PTC+A/C fallback); token charger-coolant/NTC stub for electronics fidelity. 5 OWNER FORKS all RULED 2026-07-20, folded into PR #23 as owner-ratified: (a) cabin heat = heat-pump (faithful); (b) charger coolant branch = retain token loop; (c) pack blower = per-chemistry variant (SLA/NiMH keep blower+purge; LiFePO4 delete blower, keep pad heaters; NiMH tagged @inferred); (d) waste-heat heater-core tap = ADDED to the ratified Option-B architecture (faithful, benefits all chemistries); (e) refrigerant = R-134a default with a tracked sourceability check routed to the sourcing catalog (fall back R-1234yf only if new R-134a-native components unsourceable). 4 electricsim errata routed to the module-wave session (compressor PWM wire cell; De-FEX/19°C switch unmodeled; pack fan binary vs 35%/100%; charger thermal convective vs liquid).
