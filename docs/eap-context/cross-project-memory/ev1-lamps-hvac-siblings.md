- Door actuator 16163982 = CONFIRMED direct-lift common GM "Temperature Valve Actuator" (Dorman 604-106 / ACDelco 15-72971, ~$10-50, 1994-2014 GM donors); 2-pin reversible DC gear-motor; BOTH EV1 air doors use it (no blend door). THE QUICK WIN. (Secondary sensor 16150574 = real: redux "SENSOR ASM-A/CL AIR TEMP" 05-06 item 001; just no web cross.)
- Blower motor 52473284 + PWM module 16207689 = EV1-UNIQUE service numbers (don't cross-list), but on a standard GM 4-cav Packard connector 12129565 + standard PWM scheme → donor = 1995-99 Olds Aurora/Buick Riviera A/C Power Module (GM 52470336 = ACDelco 15-8690, ~$103); Cadillac Northstar second.
- Heat-pump COMPRESSOR 27001056 — CORRECTED (@source:manual hvac-288, corrected 2026-07-20, PR #6 commit 87041da): the ORIGINAL EV1 compressor is a **dual-rolling-piston, 180V variable-speed, 3-phase AC induction** unit (NOT a scroll), capacity controlled 25–120 Hz, make/model null; ~1625W steady/2000W peak electrical INPUT (the earlier scroll framing, incl. the inferred 225-430V, is superseded) — + EHPS PS-PUMP motor 26065868 (3-phase HV, yellow Molex 1x6): AUTO-SIBLINGS FAIL — the '90s electric-compressor/heat-pump club (Honda EV Plus, Chrysler EPIC, RAV4 EV, Nissan Altra, Ford Ecostar) left no matchable specs, and every production EHPS pump is 12V DC (EV1 HV-3-phase is near-unique). Realistic path = GENERAL-MARKET SPEC-MATCH (Guchen-class HV scroll ~230-450V for the compressor — but the NANFENG NFDM34 modern substitute is **scroll-on-PMSM** vs the original's **rolling-piston-on-AC-induction**: a character/NVH difference, a cooling-class substitute (~1.5–2 kW class) NOT a mechanism-faithful match; inverter-integrated so functional-replacement not bare-motor; small 3-phase BLDC for the PS pump), NOT a drop-in. NOTE: the earlier scroll-derived ~24–34cc displacement ESTIMATE is REPLACED by the manual-printed **19 cc/rev** (@source:manual hvac-288 — "The compressor displacement is 19 cc per revolution."), a real printed fact not an inference; cooling class is computable from 19cc × speed (25–120 Hz) rather than a loose ~1.5–2 kW guess. The PS pump feeds the Saab-9000 rack (see [[ev1-sibling-id-scaled-cases]] rack).
- Climate system: reversible electric heat pump (HPVS) — reversing valve 27000715, orifice tube 27000717, accumulator 01132666, combined rad/condenser 27002771, evaporator+blower module 52467000 (bespoke air box); R-134a 0.91kg (hvac-73).
