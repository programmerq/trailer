# EV1 replica lamps and body panels plan

Sourcing/fabrication strategy for lamps + body panels (2026-07-17 owner).

**DIRECT-LIFT parts** (same P/N on EV1 and other GM vehicles): front
turn-signal lamp assembly, rear reflectors — buy outright.

**BESPOKE lamps:** headlamp + stoplamp assemblies are EV1-only →
scratch-build. Plan: harvest common GM bulb/reflector "bowls" (many GM
vehicles share similar bulb/reflector geometry) from a similar-sized donor
and fabricate only the bespoke housing; clear lenses via
classic-car-replica techniques — 3D printing (FFF/resin), forged carbon
fiber, machining, vacuforming.

**BODY PANELS:** reinforced composite plastic (similar to the Pontiac
Fiero, which used a steel spaceframe + plastic panels); owner expects most
panels are buildable via VACUFORMING (large DIY vacuform table, years out);
less-researched area.
