# EV1 replica frame-reconstruction plan

Owner's frame-reconstruction intent (2026-07-17) — THE most critical part of
the replica per the owner.

Recreate the bonded/welded aluminum spaceframe from: chassis-manual datum
points, alloy information, and as many references as possible.

- Owner must learn **SHEET-METAL CAD modeling** — the EV1 frame is largely
  formed aluminum sheet panels, not just extrusions.
- He will do real engineering and expects to **PAY for outside engineering
  services for verification**, even though no regulation requires it for a
  one-off personal build.

**Reference assets:**
- Owner has photos of several bare spaceframes.
- The YouTube videos about EV1 #212 show the bare frame from nearly every
  angle.
- The GM Heritage Center has shared substantial material with #212's owner,
  including ORIGINAL ASSEMBLY LINE VIDEO.
- Owner hopes to get 3D scan data from a physical EV1.

**NOTE (layering):** chassis-manual datum coordinates are PRINTED manual
facts → capture belongs in redux (R4-compliant), with the ev1 build repo
referencing them — same layering as sourcing
(see [[ev1-replica-sourcing-plan]]).

**Owner priority (2026-07-17):** geometry work starts with EXTRACTING
DIMENSIONS + DATUM POINTS FROM THE CHASSIS MANUAL (redux capture, R4-clean) as
the base — BEFORE building the visual-reference corpus index. The
datum-capture priority was routed to the redux workstream queue via the
coordinator on 2026-07-17.
