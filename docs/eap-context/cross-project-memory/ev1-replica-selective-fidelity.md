The owner's fidelity strategy for the EV1 replica is SELECTIVE and character-driven, not uniform.

**Modern substitutions welcome** where better or cheaper: powertrain, battery chemistry (lithium / LFP), motor, inverter. No demand for period-correct propulsion.

**Character-defining subsystems that MUST be faithful:**

1. **The EV1 brake system** — electronic rear brake actuation PLUS an electronic parking brake in the SAME rear drum, dual-motor self-energizing rear drums. This is genuinely unique to the EV1; the owner explicitly REJECTS "just drop in any EV brake." It is also the sharpest engineering wedge because it is half-electronic, directly leveraging the owner's electronics mastery.

2. **The interior / HMI** — RSA/CCU center console + IPC dash, physical controls with mechanical feedback, the "spaceship" feel.
