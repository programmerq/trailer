**INSIDE REAR-VIEW MIRROR = confirmed shared-GM DIRECT-LIFT (HIGH).** EV1 assy P/N 10240816 (@source:redux, parts/lists/09-02 item 011; windshield-wedge mount, DUAL map lights, connector 12047785 4-pin MP150, lamp-only wiring HI 1732F/LO 156/GND 350M; no compass/temp; auto-dim UNCONFIRMED). Interchange chain (oemcats): 10240816 → 10404249 (Nov 1997) → superseded by 88892505 (Oct 2002) = Donnelly 10.5" manual-dim dual-map inside mirror, standard GM wedge mount, ~31 GM cars 1987-2002. Donors: 1996-99 Buick LeSabre, 1997-2001 Century, 1993-2002 Camaro, ~2000 Grand Am, 2000-02 Impala. BUY an EARLY-vintage (1996-98) unit — late 88892505 service mirrors may carry a different pigtail than the EV1's 4-pin 12047785.

**EXTERIOR SIDE MIRRORS = EV1-specific housing → PINOUT-MATCH fallback (per owner's instruction).** EV1 "MIRROR ASM-O/S RR VIEW" LH 27000137 / RH 27000136 (@source:redux, 08-18 item 007). POWER adjust, NON-heated, NO power-fold, door-mount (2 bolts 11515929). No same-SHAPE production sibling — housing appears bespoke (Cd-0.19 aero + restoration press; 27-block P/N doesn't cross-list). Electrically it's the STANDARD GM mid-90s 3-wire-per-mirror scheme (vert/horiz/common-B+ + L/R select): motor connector 12110293 (generic 3-pin MP150; pin MAP is the discriminator, not the PN), driver-door switch 12047886 (8-pin "Switch-O/S Rear View Mirror R/Con"). LEAD pinout-match donor: 1995-2005 Chevy Cavalier / Pontiac Sunfire BASE (non-heated) power mirror (e.g. Sunfire LH 22639665, ~$25-35) — MED conf: feature/electrical match exact, shape NOT photo-proven, plan a RE-PIN pigtail + bench-test the 3 leads (literal plug-and-play unproven since the connector body is GM-generic). Saturn S-series = lineage tie, more upright housing (shape LOW). REJECT heated/power-fold/memory/turn-signal/blind-spot mirrors (extra pins / module-driven). TOP HUMAN LEAD: an r/gmev1 owner thread "I think I found the mirrors I'll use for my EV1" (Reddit post ds6d70) is login-walled/403 to all fetch tools — the OWNER should open it; may name a concrete donor.

**Methodology L8 (added):** part-number/interchange RESOLUTION is the crux of sibling-ID, and search-tool quality decides it — the rear-view sibling was found ONLY because a P/N-resolving search surfaced the 10240816 interchange chain the default web search flatly failed on. Obscure enthusiast-forum leads (Reddit) stay blocked to automated fetch → need a human.

**PARALLEL_SEARCH MCP tooling verdict (owner installed it 2026-07-18, deciding on paid tier):** web_search + web_fetch. STRONG on the hard cases — part-number/interchange resolution + obscure-forum finds (it resolved 10240816 that default WebSearch explicitly could not; surfaced the r/gmev1 thread + the Autopian quote); excerpts fuller than default. BUT the FREE TIER rate-limits hard — every worker got 2-5 of ~7 calls rejected with "add your own API key", so on any fan-out it's unreliable; web_fetch did NOT beat default against anti-bot walls (Reddit/AutoZone 403 both). NET: worth the paid key SPECIFICALLY for P/N/interchange-heavy sibling work IF paid lifts the rate cap; free tier too throttled to lean on; default WebSearch remains fine for general topology/reasoning.

**Side-mirror Fiat 500e lead — EVALUATED, NOT recommended (2026-07-18).** The owner opened the r/gmev1 thread (ds6d70); a poster there suggested a Fiat 500e mirror looks similar. Adversarial eval: NOT a good sibling — marginal look-alike only (retro egg pod Cd 0.311 vs EV1 bespoke teardrop Cd 0.19), 3-bolt mount vs EV1's 2-bolt, and decisively POWER+HEATED on a proprietary Mopar multi-pin connector (opposite of the EV1 non-heated GM 3-pin Metri-Pack 150). Its adjust motors ARE simple bidirectional DC (not module/LIN-driven) so adaptation is feasible-in-principle via a re-pin, but it loses on connector/heat-pins/mount/era/cost to the Cavalier/Sunfire GM pinout-match donor, which stays the pick. Owner agreed with the rest of the mirror assessments; PR #4 merged.
