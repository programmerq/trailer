When facilitating brainstorm / debate panels for the owner, he prefers the agent rounds to INDEPENDENTLY generate and "one-up" bold ideas rather than have him seed direction. He will deliberately WITHHOLD his own outside-the-box ideas so the panel's output is a genuine independent test, then compare afterward.

**Why:** he values the panel as an adversarial idea generator, not an echo of his own thinking.

**How to apply:** run genuine outside-the-box ideation with adversarial culling so only bold-AND-survivable ideas surface; don't fish for his ideas first.
