**External keypad = Ford recollection REFUTED → GM/AC Delco.** Owner recalled (second-hand, unconfirmed) the EV1 external keypad being a Ford part under an EV1 bezel. Method refuted it: EV1 keypad = driver B-pillar 5-button/2-digit membrane pad, P/N 27002441 ("SWITCH ASM-KEYLESS ENTRY FRT S/D (W/ MLDG)"), connector 12064980 (GM/Delphi Micro-Pack 100 9-way), scanned by the RSA (manual p.554). EVERY fingerprint is GM (P/N, connector, circuit numbers). The famous 5-button/2-digit layout is NOT Ford-exclusive — GM used it itself (Buick Riviera/Reatta B-pillar keypads, late-'80s AC Delco; modern GM accessory keypad). So it's a look-alike; likely donor is GM/AC Delco, exact vehicle open. NOTE: this also means the earlier "Ford keypad" methodology example was over-stated and was downgraded to unconfirmed then refuted (commit 550c89c).

**New methodology lessons:**
- **L6 — gate sibling-casing hunts on MODULE CLASS.** Electronic module → tooled amortized enclosure → real casing siblings. Passive junction block → harness-specific breakout → bespoke; reconstruct from connector footprints, don't hunt a donor block.
- **L7 — verify recollected cross-make attributions against the part's own numbering before recording.** The keypad "Ford" recollection failed against all-GM fingerprints; a distinctive-but-shared layout is non-diagnostic.

**Owner packaging-sibling claims (recorded as claims-to-verify, not repo-confirmed):** owner says only TJB+SDM+BTCM have packaging siblings (LHJB/RHJB none, dims inferred from references); owner's own sleuthing: BTCM matches 1995 Firebird EBTCM in shape/size/connector PNs (in-repo BTCM connectors are 12110113/12110626/12129088; repo carries no Firebird/EBTCM-as-sibling string — owner's external hypothesis); SDM "visually similar to several others of this era."
