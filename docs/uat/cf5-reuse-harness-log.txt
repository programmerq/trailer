ORACLE: top-level app-window count by WM_CLASS ("trailer") — the same selector
the harness uses to find the app window. The File -> Open dialog shares that
WM_CLASS, so every count is taken AFTER the dialog closes and the UI settles.
Reuse == count stays 1; no-clobber == count goes to 2.

Behaviour under test lives in Application::openFiles() (src/app/Application.cpp),
the reuseCandidate / takeReuseOrFresh consume-once logic: it fires only under a
real activeWindow()/single live window, which is exactly why a real WM (not
QT_QPA_PLATFORM=offscreen) is required to observe it.
